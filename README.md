# Корзинка — цены и список покупок

Сайт для покупателей (RU/UZ, работает без интернета) + скрытая админка для загрузки Excel. Зависимостей нет, нужен только Node.js 18+.

## Запуск
    ADMIN_PASSWORD=ваш_пароль node server.js        # http://localhost:3000

## Переменные
- `ADMIN_PASSWORD` — пароль админки (обязательно)
- `ADMIN_PATH` — адрес админки, по умолчанию `/admin` (лучше поменять, например `/panel-x7k2`)
- `DATA_DIR` — где хранится база (по умолчанию `./data`)

## Деплой (Render / Railway / VPS)
Build command пустой, Start command: `node server.js`. Добавьте переменные выше.
**Важно:** база цен хранится в `DATA_DIR`. Подключите постоянный диск (Render: Disks → mount `/data`, `DATA_DIR=/data`), иначе после перезапуска сервер вернётся к стартовой базе из `seed/`. На бесплатном тарифе без диска делайте «Скачать резервную копию» в админке.

## Обновление цен
Откройте `ВАШ_САЙТ/admin` → пароль → выберите Excel (название + цена) → «Проверить файл» → «Применить». Совпало название — обновится цена и запишется история, нет в базе — добавится. Цены ≥ 1 000 000 и 0 считаются «по весу» и не затирают старую цену.
